# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Frontend
- Implemented modern UI with dark/light mode toggle
- Added theme system using CSS variables
- Improved responsive design and accessibility
- Enhanced UI components with consistent styling

## [0.1.2] - 2025-03-26

### Backend
- Implemented map creation and configuration API
- Added map data storage with auto-save functionality
- Implemented pin placement on map coordinates
- Added pin repositioning functionality for maps
- Implemented map access control to restrict maps to owner
- Added API endpoints for map management (create, update, delete)

## [0.1.1] - 2025-03-19

### Frontend
- Implemented map integration with Leaflet.js
- Added pin placement functionality on map coordinates
- Added pin repositioning functionality (drag to reposition)
- Implemented basic map controls (zoom in/out, pan, reset view)
- Added custom pin styling options (color)

## [0.1.0] - 2025-03-12

### Backend
- Implemented image upload functionality with support for JPG, PNG, and GIF formats
- Added 5MB file size limit for uploads
- Implemented image display with correct aspect ratio
- Added file-based storage system with auto-save functionality
- Implemented basic error handling for storage operations
- Added basic access control to restrict image access to owner

### Frontend
- Added image upload interface
- Implemented image display with correct aspect ratio
- Added pin placement functionality (click to place pin)
- Added pin repositioning functionality (drag to reposition)
- Implemented basic pin styling options (color, size)

### Backend
- Initial project setup
- Basic server configuration
- Development environment setup

### Frontend
